# 不买开发者账号（$99）的三种活法

先把话说死：**不买 Apple Developer Program，TestFlight 就用不了。** 这不是配置问题，是苹果的硬规则——TestFlight 是付费会员专属的分发通道，没有免费替代品。

但这不等于这个 App 白写了。你还有三条退路，按"安全性"排序。

---

## 0. 免费 Apple ID 到底能干什么

| 能力 | 免费 Apple ID | 付费（$99/年） |
| --- | --- | --- |
| 装到自己 iPhone 上用 | ✅ 可以 | ✅ |
| 签名有效期 | **7 天**，到期要重签 | 1 年 |
| 同时装几个自签 App | 最多 3 个 | 不限 |
| TestFlight 分发 | ❌ | ✅ |
| 给别人装（Ad Hoc） | ❌ | ✅ |
| 上架 App Store | ❌ | ✅ |
| 相机 / 相册 / Apple Log | ✅ **完全正常** | ✅ |
| 手动快门 / 胶片渲染 | ✅ **完全正常** | ✅ |

**重要**：免费账号限制的只是"签名有效期"和"分发能力"，**不影响任何相机功能**。Apple Log 取决于你的机型（iPhone 15 Pro+），跟账号没关系。

## 路线一：借一台 Mac，用免费 Apple ID 直接跑（最安全）

苹果官方支持的方式，不用第三方工具，不用把密码交给别人。

**需要**：一台实体 Mac（朋友/同事的）+ 一根数据线 + 20 分钟。

1. 在 Mac 上打开 `FilmSim.xcodeproj`
2. Xcode → **Settings → Accounts → ＋** → 登录你的**普通 Apple ID**（不用付费）
3. 点工程 → TARGETS → **Signing & Capabilities**
4. Team 选 **你的名字 (Personal Team)**，勾上 Automatically manage signing
5. Bundle Identifier 填一个没被占用的，例如 `com.zhangsan.filmsim`
6. iPhone 用数据线连 Mac → 手机上点「信任此电脑」
7. Xcode 顶部设备下拉选你的 iPhone（**不能选模拟器**）→ `Cmd + R`
8. 手机：设置 → 通用 → VPN与设备管理 → 信任你的 Apple ID → 打开 App

**7 天后**：App 打不开（提示"无法验证"）。回到 Mac，重新 `Cmd + R` 一次，又是 7 天。

> 优点：最安全、苹果原生、没有账号泄露风险。
> 缺点：每周都要摸到那台 Mac。

## 路线二：云端出「未签名 ipa」+ Windows 自签（唯一不用 Mac 的免费路）

思路：Codemagic 的免费云 Mac 只负责**编译**（不需要任何 Apple 账号），产出一个没签名的 `.ipa`；
然后在你自己的 Windows 上，用签名工具拿你的免费 Apple ID 给它签名并装进手机。

工程里已经配好了这个工作流：`codemagic.yaml` 里的 **`ios-unsigned`**。

### 2.1 云端构建（免费，不需要账号）

1. 按 [codemagic.md](codemagic.md) 第 3、4.1 节把代码推到 GitHub、在 Codemagic 里添加应用
2. **不用买账号，也不用填 API Key**——这个工作流完全不碰签名
3. 进入 App → **Start new build** → Workflow 选 **`FilmSim → 未签名 ipa`** → Start
4. 等 8–12 分钟，构建完成
5. 在构建结果页的 **Artifacts** 里下载 `FilmSim-unsigned.ipa`（几 MB）

> 这一步失败的话，说明代码本身有编译错误——跟账号无关，把日志里的 `error:` 行发我。

### 2.2 Windows 准备（10 分钟）

| 要装的东西 | 说明 |
| --- | --- |
| **Apple 设备 / iTunes** | 微软商店搜「Apple Devices」装；用来给 iPhone 提供 USB 驱动 |
| **Sideloadly** | <https://sideloadly.io> 下载安装（免费） |
| 数据线 | 原装或 MFi 线，杂牌线经常只充电不传数据 |

手机上：
- 设置 → 隐私与安全性 → **开发者模式** → 打开 → 重启（iOS 16+ 必须）
- 连上电脑后点「信任此电脑」

### 2.3 签名安装（5 分钟）

1. iPhone 插上 Windows，打开 **Sideloadly**，顶部应该能看到你的设备
2. 把 `FilmSim-unsigned.ipa` 拖进 Sideloadly 的 IPA 框（或点 IPA 图标选文件）
3. **Apple ID** 填你的账号（建议用一个**专用小号**，见 2.5）
4. 点 **Start** → 输入密码
   - 如果它要的是「App 专用密码」，去 <https://appleid.apple.com> → 登录与安全 → App 专用密码 → 生成一个，粘贴进去
5. 等 1–3 分钟，手机桌面上出现 App
6. 第一次打开会提示「不受信任的开发者」→ 手机：设置 → 通用 → **VPN与设备管理** → 点你的 Apple ID → **信任**

### 2.4 7 天续签

到期后 App 点开就闪退。重新插上电脑，Sideloadly 再跑一次同一个 ipa 就行（1 分钟）。
或者用 **AltStore + AltServer**（Windows 后台常驻），同一个 Wi-Fi 下自动续签，不用插线。

### 2.5 风险，必须知道

- **要交出 Apple ID 密码**（或 App 专用密码）给第三方工具。**强烈建议注册一个专用小号**，只用来签名，别用你的主账号。
- 免费账号自签是苹果官方允许的开发行为，但**高频、多设备**可能触发风控，表现为「此 Apple ID 已被锁定」。
- Sideloadly / AltStore 依赖苹果的私有接口，**苹果改接口时工具会暂时失效**，等工具作者更新。
- 免费签名**不能给别人装**，也**不能上架**。
- 7 天过期是个硬限制，改不了。

## 路线三：蹭一个付费账号（唯一能用 TestFlight 的免费路）

如果你有朋友/同事已经是付费开发者：

1. 让他在 <https://appstoreconnect.apple.com> → **用户和访问** → 邀请你的 Apple ID，角色给 **App Manager**
2. 你接受邀请后，就能在他的团队下上传 build
3. TestFlight 内部测试把你加进去，手机上就能装

**代价**：App 挂在他名下（App Store 上显示的是他的开发者名），他随时可以把你踢掉；上架也要用他的身份。适合"我们俩一起玩"，不适合长期。

## 我的建议

**先用路线二装上试玩 7 天，再决定要不要买。**

理由：你现在还没见过这个 App 跑起来。花 $99 之前，先确认三件事——
1. 胶片模拟的颜色你喜不喜欢（11 档里总有一档对味，也可能都不对）
2. 手动快门的手感是不是你想要的
3. 你的机型支不支持 Apple Log（iPhone 15 Pro 以下就别指望了）

这三件事验证完，再决定"这东西值不值得每年 $99"。工程不会过期，账号随时能买。

如果你试完觉得"这就是我要的，而且我想让朋友也用"，那 $99 就是门票，没有替代方案——一年 700 多块，比一台二手胶片机便宜。

## 常见问题

**Q：免费签名会不会影响照片画质或 Apple Log？**
不会。签名只决定"系统允不允许这个 App 运行"，跟相机 API、渲染管线完全无关。

**Q：7 天到期是什么表现？**
点图标闪退，或者提示"App 不再可用"。数据（相册里的照片）不受影响——照片存在系统相册里，不属于 App。

**Q：改系统时间能延长吗？**
不能。

**Q：苹果有免费申请开发者账号的通道吗？**
只有**非营利组织、政府机构、教育机构**可以申请年费豁免，个人开发者不行。

**Q：不签名直接装行不行？**
不行，iOS 强制要求所有可执行代码有有效签名。

**Q：那我用 TestFlight 的公开链接呢？**
公开链接也是付费账号才能生成的。
